# UniFlow-RS project page

Static GitHub Pages project site at `/uniflow-rs/`. This subdirectory is independent of the personal homepage. No build step or server-side service is required.

Preview from the repository root: `python3 -m http.server 8765`, then open `http://localhost:8765/uniflow-rs/`.

Only manuscript-derived text, figures and saved qualitative demonstrations are included. The animation is prerecorded, not live inference. The manuscript PDF is the author-named preprint. No unassigned arXiv identifier, acceptance claim or unreleased code URL is included.

Update the Paper link and BibTeX once the arXiv identifier is available. Add the public code link once its repository is ready. Author affiliations were confirmed by the authors.

Layout inspired by https://flowdis.github.io/; implementation is original HTML/CSS/JavaScript. No analytics, cookies, external fonts or runtime dependencies.
